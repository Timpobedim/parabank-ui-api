# PB-002. Перевод на отрицательную сумму проходит — деньги идут в обратную сторону

| Поле | Значение |
|---|---|
| Серьёзность | Critical — можно списать деньги с чужого счёта, указав его как получателя |
| Приоритет | High |
| Окружение | parasoft/parabank (digest `sha256:747453a0…`), http://localhost:8090/parabank · 11.09.2026 |
| Воспроизводимость | стабильно |
| Автотест | `tests/api/test_known_defects_api.py::test_negative_transfer_amount_is_rejected` (xfail) |

## Шаги

1. Клиент с двумя счетами (см. PB-001).
2. `POST /services/bank/transfer?fromAccountId=<A>&toAccountId=<B>&amount=-10`.

## Ожидаемый результат

400: сумма перевода должна быть положительной.

## Фактический результат

`200 Successfully transferred $-10 from account #A to account #B` — счёт B уменьшается,
счёт A увеличивается.
