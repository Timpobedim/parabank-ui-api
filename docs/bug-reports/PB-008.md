# PB-008. Отказ в кредите возвращает ключ локализации вместо текста

| Поле | Значение |
|---|---|
| Серьёзность | Trivial — клиенту API приходится знать внутренние ключи |
| Приоритет | Low |
| Окружение | parasoft/parabank (digest `sha256:747453a0…`), http://localhost:8090/parabank · 11.09.2026 |
| Воспроизводимость | стабильно |
| Автотест | `tests/api/test_known_defects_api.py::test_loan_denial_message_is_human_readable` (xfail) |

## Шаги

1. Клиент с балансом $515.50.
2. `POST /services/bank/requestLoan?customerId=…&amount=1000&downPayment=600&fromAccountId=<CHECKING>`.

## Ожидаемый результат

Понятная причина отказа, как в интерфейсе: «You do not have sufficient funds for the given down payment.».

## Фактический результат

`{"approved": false, "message": "error.insufficient.funds", "accountId": null}` — ключ из файла
локализации вместо текста.
