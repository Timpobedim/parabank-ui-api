# PB-005. Текстовый ответ объявлен как application/json

| Поле | Значение |
|---|---|
| Серьёзность | Minor — нарушение контракта: клиент, разбирающий ответ по Content-Type, падает |
| Приоритет | Medium |
| Окружение | parasoft/parabank (digest `sha256:747453a0…`), http://localhost:8090/parabank · 11.09.2026 |
| Воспроизводимость | стабильно |
| Автотест | `tests/api/test_known_defects_api.py::test_operation_response_matches_content_type` (xfail) |

## Шаги

1. `POST /services/bank/deposit?accountId=<A>&amount=10` с `Accept: application/json`.

## Ожидаемый результат

Либо JSON-тело (например, `{"message": "…"}`), либо `Content-Type: text/plain`.

## Фактический результат

`Content-Type: application/json`, а тело — строка `Successfully deposited $10 to account #…`,
которая не является JSON. Так же отвечают `/transfer`, `/withdraw` и `/customers/update/{id}`.
