# PB-003. Перевод на тот же самый счёт проходит

| Поле | Значение |
|---|---|
| Серьёзность | Minor — операция бессмысленна, но засоряет историю двумя транзакциями |
| Приоритет | Low |
| Окружение | parasoft/parabank (digest `sha256:747453a0…`), http://localhost:8090/parabank · 11.09.2026 |
| Воспроизводимость | стабильно |
| Автотест | `tests/api/test_known_defects_api.py::test_transfer_to_the_same_account_is_rejected` (xfail) |

## Шаги

1. `POST /services/bank/transfer?fromAccountId=<A>&toAccountId=<A>&amount=10`.

## Ожидаемый результат

400: счёт получателя должен отличаться от счёта отправителя.

## Фактический результат

`200 Successfully transferred $10 from account #A to account #A`. В UI у клиента с одним счётом
форма перевода по умолчанию подставляет один и тот же счёт в оба списка и тоже пропускает перевод.
