# PB-001. Перевод и снятие больше остатка проходят, баланс уходит в минус

| Поле | Значение |
|---|---|
| Серьёзность | Critical — нарушение бизнес-правила, деньги «из воздуха» |
| Приоритет | High |
| Окружение | parasoft/parabank (digest `sha256:747453a0…`), http://localhost:8090/parabank · 11.09.2026 |
| Воспроизводимость | стабильно |
| Автотест | `tests/api/test_known_defects_api.py::test_transfer_exceeding_balance_is_rejected` (xfail) |

## Шаги

1. Зарегистрировать клиента — у него один счёт CHECKING с балансом $515.50.
2. Открыть второй счёт: `POST /services/bank/createAccount?customerId=…&newAccountType=1&fromAccountId=<CHECKING>`.
3. `POST /services/bank/transfer?fromAccountId=<CHECKING>&toAccountId=<SAVINGS>&amount=100000`.

## Ожидаемый результат

Отказ (4xx с понятным сообщением), балансы не меняются.

## Фактический результат

`200 Successfully transferred $100000 from account #… to account #…`, баланс счёта-источника —
`-99634.50`. Так же проходит `POST /withdraw` на сумму больше остатка. В обзоре счетов UI при этом
показывает отрицательный баланс и «Available Amount $0.00».
