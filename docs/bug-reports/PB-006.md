# PB-006. Знак «+» в телефоне при обновлении профиля через API превращается в пробел

| Поле | Значение |
|---|---|
| Серьёзность | Major — порча данных клиента |
| Приоритет | Medium |
| Окружение | parasoft/parabank (digest `sha256:747453a0…`), http://localhost:8090/parabank · 11.09.2026 |
| Воспроизводимость | стабильно |
| Автотест | `tests/api/test_known_defects_api.py::test_update_keeps_plus_in_phone_number` (xfail) |

## Шаги

1. `POST /services/bank/customers/update/<id>?…&phoneNumber=%2B79991234567&…` — «+» закодирован
   по правилам URL как `%2B`.
2. `GET /services/bank/customers/<id>`.

## Ожидаемый результат

`"phoneNumber": "+79991234567"`.

## Фактический результат

`"phoneNumber": " 79991234567"`. Пробел получается и из `%2B`, и из «сырого» `+` — похоже,
сервер декодирует параметры запроса дважды. При регистрации через форму «+» сохраняется верно.
