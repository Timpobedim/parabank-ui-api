# PB-007. Ответ createAccount показывает баланс 0 вместо зачисленных $100

| Поле | Значение |
|---|---|
| Серьёзность | Minor — ответ расходится с фактическим состоянием |
| Приоритет | Low |
| Окружение | parasoft/parabank (digest `sha256:747453a0…`), http://localhost:8090/parabank · 11.09.2026 |
| Воспроизводимость | стабильно |
| Автотест | `tests/api/test_known_defects_api.py::test_created_account_response_shows_actual_balance` (xfail) |

## Шаги

1. `POST /services/bank/createAccount?customerId=…&newAccountType=1&fromAccountId=<CHECKING>`.
2. `GET /services/bank/accounts/<id из ответа>`.

## Ожидаемый результат

В ответе шага 1 — тот же баланс, что и на шаге 2.

## Фактический результат

Шаг 1: `{"id": …, "type": "SAVINGS", "balance": 0}`. Шаг 2: `"balance": 100.00` — стартовый взнос
списан с CHECKING и зачислен уже после формирования ответа.
