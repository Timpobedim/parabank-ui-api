# PB-011. Слишком длинное значение поля — ложная ошибка «This username already exists.»

| Поле | Значение |
|---|---|
| Серьёзность | Major — пользователь не может зарегистрироваться и не понимает почему |
| Приоритет | High |
| Окружение | parasoft/parabank (digest `sha256:747453a0…`), Chromium 151 (Playwright 1.62) · 11.09.2026 |
| Воспроизводимость | стабильно |
| Автотест | `tests/ui/test_encoding_ui.py::test_overlong_city_gets_its_own_validation_message` (xfail) |

## Шаги

1. Открыть **Register**, заполнить форму корректно, в поле **City** ввести 21 символ.
2. Нажать **Register**.

## Ожидаемый результат

Сообщение у поля **City** о допустимой длине (или ограничение `maxlength` у поля ввода).

## Фактический результат

Форма возвращается с ошибкой у поля **Username**: «This username already exists.», хотя логин
новый; клиент не создаётся.

## Найденные ограничения длины

Бинарным поиском по каждому полю: имя и фамилия — 30, улица — 45, город, штат, индекс, телефон,
логин и пароль — 20, SSN — 15. Ни одно из ограничений не показано пользователю. Фабрика тестовых
данных (`src/parabank/data/factories.py`) держит значения в этих пределах.
